# Library React

A component-based online bookstore interface built while learning React.

## Features

- Reusable book components
- Featured and discounted sections
- Explore and cart experiences
- Client-side routing
- Responsive layouts

## Built With

- React
- Create React App
- JavaScript
- React Router

## Requirements

- Node.js 18 or newer
- npm

## Installation

```bash
git clone https://github.com/Miingo954/library-react.git
cd library-react
npm install
```

## Run Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm start
npm run build
npm test
```
